# Révisions SUAP

Appli d’entraînement continu au secours d’urgence aux personnes (équipier SUAP / PSE) : séance du jour en répétition espacée avec degré de certitude, banc de décision (position, oxygène, action prioritaire), fiches, quiz, mises en situation en équipage VSAV, mémos, chiffres clés, lexique et sauvegarde de la progression.

Sources : GDO DGSCGC « Secours et soins d’urgence aux personnes » (nov. 2022) et Références techniques nationales PSE (juillet 2026).

Usage personnel. Installable sur téléphone (PWA) via GitHub Pages.
